# Проект "Банковские операции"

##Описание:

Виджет банковских пераций клиента.

Функционал содердит:

1.Маскировку карт и счетов.

2.Фильтрацию операций по ключу и сортировку операций по дате.

3.Функция преобразования даты.

4.Реализованы генераторы для работы с транзакциями.

5.Реализовано считывание финансовых операций из CSV- и XLSX-файлов.

6.Написана функция main в модуле main , которая предоставляет пользовательский интерфейс.

##Тестирование:

###Наш проект покрыт юнит-тестами pytest.

###1.Чтобы установить pytest, используйте команду:

###poetry add --group dev pytest

###2.Для их запуска выполните команду:

###pytest

###3.В pytest для анализа покрытия кода надо поставить библиотеку pytest-cov:

###poetry add --group dev pytest-cov

###4.для проверки покрытия тестами выполните команду:

###pytest --cov
